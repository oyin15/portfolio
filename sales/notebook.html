E-commerce Sales & Customer Analysis — Hearthline Goods¶

Author: Oyindamola Obisesan

Client question: Hearthline Goods, an online home & kitchen store, wants to know how the business performed over the last two fiscal years, which products and marketing channels actually make money, and where to focus to grow repeat customers.

Data: 32,000+ order lines, 19,000 orders and 12,000 customers, Oct 2024 – Sep 2026 (FY25 = Oct 2024–Sep 2025, FY26 = Oct 2025–Sep 2026). The store and its data are fictional, simulated to look like a real direct-to-consumer business.

def kpis(d):
    orders = d.groupby("order_id").agg(rev=("net_revenue", "sum"), cust=("customer_id", "first"))
    cust_orders = orders.groupby("cust").size()
    return pd.Series({
        "Net revenue": d.net_revenue.sum(),
        "Orders": orders.shape[0],
        "Customers": cust_orders.shape[0],
        "Avg order value": orders.rev.mean(),
        "Orders per customer": cust_orders.mean(),
        "Gross margin % (after returns)": d.gross_profit.sum() / d.kept_revenue.sum() * 100,
        "Return rate % (of revenue)": d.loc[d.returned == 1, "net_revenue"].sum() / d.net_revenue.sum() * 100,
        "Discounted orders %": d.groupby("order_id").discounted.first().mean() * 100,
    })
kpi_table = pd.DataFrame({fy: kpis(df[df.fy == fy]) for fy in ["FY25", "FY26"]})
kpi_table["Change %"] = (kpi_table.FY26 / kpi_table.FY25 - 1) * 100

cust = df.groupby("customer_id").agg(first=("order_date", "min"), orders=("order_id", "nunique"),
                                     channel=("acquisition_channel", "first"), revenue=("net_revenue", "sum"))
repeat_rate = (cust.orders > 1).mean() * 100

6. Customer segments (RFM)¶

Each customer is scored 1–4 on Recency (days since last order), Frequency (number of orders) and Monetary value (total spend), as of 30 Sep 2026. Scores are combined into plain-English segments a marketing team can act on.

In [7]:
asof = pd.Timestamp("2026-10-01")
rfm = df.groupby("customer_id").agg(last=("order_date", "max"), F=("order_id", "nunique"), M=("net_revenue", "sum"))
rfm["R_days"] = (asof - rfm["last"]).dt.days
rfm["R"] = pd.qcut(rfm.R_days, 4, labels=[4, 3, 2, 1]).astype(int)
rfm["Fs"] = np.select([rfm.F >= 4, rfm.F == 3, rfm.F == 2], [4, 3, 2], 1)
rfm["Ms"] = pd.qcut(rfm.M, 4, labels=[1, 2, 3, 4]).astype(int)

def segment(r):
    if r.R >= 3 and r.Fs >= 3: return "Champions"
    if r.R >= 3 and r.Fs == 2: return "Loyal"
    if r.R == 4 and r.Fs == 1: return "New"
    if r.R <= 2 and r.Fs >= 2: return "At risk"
    if r.R == 3 and r.Fs == 1: return "Promising"
    return "Lapsed"
rfm["segment"] = rfm.apply(segment, axis=1)

seg_order = ["Champions", "Loyal", "Promising", "New", "At risk", "Lapsed"]
seg = (rfm.groupby("segment").agg(customers=("F", "size"), revenue=("M", "sum"), avg_orders=("F", "mean"),
                                  avg_spend=("M", "mean"), avg_days_since=("R_days", "mean"))
          .reindex(seg_order)
          .assign(share_customers_pct=lambda d: d.customers / d.customers.sum() * 100,
                  share_revenue_pct=lambda d: d.revenue / d.revenue.sum() * 100))

7. Cohort retention¶

Customers are grouped by the month of their first order. Each cell shows the share of that cohort that placed another order N months later. FY25 cohorts are used so every cohort has a full 12 months of history.

10. Recommendations¶

  1. Shift budget from Paid Social toward Email/Referral and Organic Search. Their customers repeat far more often and are worth much more over time.
  2. Run a win-back campaign for the At-risk segment — repeat buyers who haven't ordered in months are the cheapest revenue to recover.
  3. Limit discounts to Black Friday and the holidays. Year-round codes cut margin without improving repeat purchase.
  4. Fix Tableware returns (better photos, sizing and packaging notes); it has the highest return rate in the catalog.
  5. Plan inventory and staffing for Nov–Dec, which bring in more than a fifth of annual revenue, and follow up holiday buyers with a January re-engagement offer, since they are the least likely to return.
  6. Track 90-day repeat rate by acquisition channel monthly as the main growth health metric.

Limitations: data is fictional; marketing spend is not included, so channels are compared on customer value rather than ROI.
